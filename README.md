# 🧠 NovaMind-v2 — AI-powered web assistant

![Python](https://img.shields.io/badge/Python-3.11.5+-blue)
![Flask](https://img.shields.io/badge/Flask-2.0+-green)
![License](https://img.shields.io/badge/License-MIT-yellow)
![Status](https://img.shields.io/badge/Status-Development-orange)

Умный веб-помощник на базе ИИ с возможностью генерации кода, изображений и управления файлами. Работает на локальном сервере с полной историей чата и кастомизацией команд.

> **NovaMind-v2 — платформа вокруг подключаемых моделей, а не собственная foundation model.** Мы не заявляем паритет с Claude, GPT или Gemini: базовые модели и инфраструктура этих компаний несравнимо масштабнее. Цель — безопасный, наблюдаемый и расширяемый сервис с честной деградацией и подключаемыми провайдерами.

## 🫧 Liquid Glass

Весь интерфейс — фон, кнопки, окно чата, настройки и окно входа — оформлен
«живым стеклом»: матовые поверхности с `backdrop-filter`, анимированный aurora-фон,
тема Aurora и спокойный режим без лишних анимаций. Подробности — **[LIQUID_GLASS.md](LIQUID_GLASS.md)**.

Поиск в интернете показан как процесс: анимированная сцена → подпись
«Поищу в интернете» → реальные шаги → печатающийся ответ → **список источников
внизу пузыря**. Рассуждения модели выводятся в отдельной сворачиваемой панели.

## 🐧 Маленький Linux

В основном чате включите **«Инструменты»** и попросите, например: «Запусти тесты,
посмотри ошибку, исправь её и проверь ещё раз». Агент получает настоящий вывод и код
завершения команды. В сообщении можно раскрыть журнал вызовов. Для ручной команды
откройте **«Файлы» → «Терминал»**: он работает в той же папке, что и агент этого
диалога. Там же доступны дерево файлов, просмотр и ZIP.

Терминал выключен по умолчанию. Для доступа агента нужны `TERMINAL_ENABLED=1`,
вход через Google или как администратор и разрешённые инструменты в текущем ходе. Гость не
получает shell от включения кнопки. Действуют ограничения команд, путей и времени;
это не отдельная виртуальная машина. На публичном сервере изолируйте процесс и
ограничьте доступ (`TERMINAL_STRICT_ADMIN=1`). Для поиска и генерации медиа Linux не нужен.

## 🤖 Агентный режим

Основной чат использует `POST /api/agent/react`. Подключённая языковая модель может
ответить сразу или вызвать инструмент. Его **фактический результат либо ошибка**
возвращается модели; только затем она выбирает следующее действие. Например, имя
файла может прийти из вывода команды, а необходимость повторного запуска — из ошибки
теста. Журнал в интерфейсе показывает то, что произошло, а не план, который сервер
безусловно исполнит. Независимые вызовы MCP на чтение могут выполняться вместе.

В новом браузере **«Инструменты» выключены**. Включение разрешает действия, но не
заставляет искать в интернете, генерировать файл или запускать терминал. ReAct
принимает нативные вызовы функций или отдельный JSON-вызов; исполняются только
инструменты из разрешённого реестра с подходящими аргументами. Опасные действия
запрашивают подтверждение при стандартной политике (`AGENT_CONFIRM=danger`);
`AGENT_CONFIRM=write` запрашивает его и перед записью/генерацией.

**Автоматический выбор инструментов.** Браузер отправляет `auto_tools: true` вместе с
разрешением на инструменты. Сервер оценивает цель запроса, ранжирует доступные
инструменты и подключённые MCP-серверы/инструменты, добавляет shortlist в контекст модели
и показывает событие `selection` в таймлайне. По умолчанию режим **консультативный**:
модель видит все разрешённые схемы и может выбрать другой инструмент по смыслу задачи.
`AUTO_TOOLS_STRICT=1` включает жёсткую фильтрацию; `mcp_call`, `mcp_list` и релевантные
инструменты остаются доступны для Recovery. Права роли, capability-токен, подтверждения
и лимиты шагов действуют точно так же — автоматический выбор ничего не разрешает сверх них.

**MCP.** Администратор подключает сервер в настройках. Модель получает схемы его
инструментов и читает результаты `mcp_call` так же, как вывод терминала. Для неадминистраторов
MCP закрыт, если явно не включён `MCP_ALLOW_USER_READ=1`; даже тогда доступны только
инструменты с `readOnlyHint=true`. Выбор сервера и инструмента модель делает сама из
обнаруженного каталога; пользователю не нужно указывать `server_id`.

Для отдельного ReAct-запуска предусмотрены API уточнения и завершения:
`POST /api/agent/answer` продолжает приостановленный запуск из сохранённого
SQLite-контекста, а `POST /api/agent/finish` фиксирует `confirmed`, `continued`
или `abandoned`. Workspace изолируется по владельцу и чату; доступны дерево,
просмотр и ZIP в `/api/agent/workspace/*`. GitHub-копия, Diff, локальный коммит
и подтверждённая публикация обслуживаются `/api/agent/github/*`.

Лимиты задаются `AGENT_MAX_STEPS`, `AGENT_MAX_TOKENS` и `AGENT_TIMEOUT`.
Встроенный `local_demo` остаётся офлайн-демо: он полезен без ключей, но не
является полноценной языковой моделью и честно сообщает об ограничениях.

**Статус миграции:** основной браузерный чат и кнопка остановки работают через
`POST /api/agent/react`; уточнения, подтверждения и выбор исхода запуска также
используют новый API. Совместимые серверные маршруты старого агента и его
пакет пока остаются в репозитории для Telegram, расписаний и других интеграций.
Их удаление, миграция соответствующих сценариев и полный аудит истории Git —
ещё не завершены.

## 💻 Использование

### Основной интерфейс

1. **Текст** — отправьте вопрос в основном чате.
2. **Действия** — включите «Инструменты» над полем ввода. Опишите результат, а не последовательность команд.
3. **Озвучка ответа** — нажмите **🔊 под нужным сообщением**. Это чтение уже готового ответа, а не новый запрос агенту. Если серверный TTS недоступен, возможен браузерный резерв, когда его поддерживает браузер.

### 🎨 Изображения и аудио в переписке

- **Создать:** «Нарисуй маяк в тумане» или «Озвучь: добро пожаловать». Результат — картинка или аудиоплеер с возможностью скачать файл.
- **Выбрать модель:** нажмите **«🎨 Изображения»** над полем ввода. «Авто» позволяет выбирать из доступных моделей. Явный выбор закрепляет точную пару провайдер/модель **для изображений в этом браузере**; текстовая модель и настройки других пользователей не меняются. При отказе выбранной модели агент не подменяет её другой.
- **Изменить:** нажмите **«Изменить» под картинкой** или **«Изображения» → «Изменить файл…»**. Опишите правку, например «замени небо на ночное». Оригинал остаётся на месте; новый результат появляется в чате. Принимаются PNG, JPEG и WebP до 8 МиБ и 24 Мп. Ссылку на произвольный файл сервер не загружает. Если провайдер вернул только внешнюю ссылку, скачайте изображение и приложите его как файл.
- **Кому отправляется исходник:** байты изображения получает медиапровайдер. При «Авто» возможны повторные попытки у других подходящих провайдеров. Для привязки к одному провайдеру выберите конкретную модель с пометкой «редактирование».

**Что подключить.** Для ReAct выберите рабочую облачную или локальную языковую модель.
Для медиа нужен отдельный подключённый провайдер подходящей модальности. Варианты:
`POLLINATIONS_API_KEY` для генерации изображений, `GEMINI_API_KEY` для совместимых
Gemini Image/TTS, `OPENROUTER_API_KEY` для подходящих моделей OpenRouter, либо свой
`IMAGE_GENERATION_URL` / `AUDIO_TTS_URL`. Для правки через свой сервис дополнительно
задайте `IMAGE_EDIT_URL` (multipart API `/images/edits`). Пример — в `.env.example`.

Каталог агента учитывает подключение и тариф. По умолчанию доступны бесплатные
модели и явно настроенные собственные endpoints (их цену определяет ваш сервис).
`MEDIA_ALLOW_PAID=1` разрешает и платные/пробные модели на уровне сервера.
Доступность конкретной модели, квоты и стоимость зависят от аккаунта провайдера.
Если ни одна модель не подходит, результатом будет ошибка, а не фиктивная картинка.

### Примеры команд

```
# Простой вопрос
Как работает Python?

# Генерация кода
@code напиши калькулятор на Python с GUI

# Генерация изображения
Нарисуй закат в горах

# Получение истории
/history

# Очистка чата
/clear
```

## ⚙️ Конфигурация

### Переменные окружения

Создай файл `.env` в корне проекта:

```env
# Flask
FLASK_ENV=development
FLASK_DEBUG=True
SECRET_KEY=your_secret_key_here

# Cloud API ключи (необязательно)
# GROQ_API_KEY=your_key_here
# CEREBRAS_API_KEY=your_key_here
# OPENROUTER_API_KEY=your_key_here

# OpenAI-compatible сервер (Ollama, LM Studio, vLLM, LocalAI или удалённый URL)
# Если cloud-ключей нет, приложение использует этот endpoint.
OPENAI_BASE_URL=http://127.0.0.1:11434/v1
OPENAI_API_KEY=
OPENAI_MODEL=llama3.2

# Можно использовать альтернативные имена:
# AI_BASE_URL=https://your-host.example.com/v1
# AI_API_KEY=your_key
# AI_MODEL=your_model
# LOCAL_LLM_URL=http://127.0.0.1:1234/v1
# LOCAL_LLM_MODEL=local-model

# Параметры сервера
HOST=0.0.0.0
PORT=5000
```

Если `GROQ_API_KEY`, `CEREBRAS_API_KEY` и `OPENROUTER_API_KEY` не заданы, чат автоматически работает через `OPENAI_BASE_URL`. Для Ollama достаточно запустить модель локально и оставить URL по умолчанию. Для удалённого OpenAI-compatible сервера укажи его базовый URL, например `https://your-host.example.com/v1`, и при необходимости API-ключ. Модель выбирается только через `OPENAI_MODEL`/`AI_MODEL` и больше не выбирается в главном экране чата.

Локальные модели получают те же возможности, что Groq и OpenRouter: потоковые ответы, вызов инструментов, JSON-режим, рассуждения, vision и учёт токенов. Поддерживаются Ollama, LM Studio, llama.cpp, vLLM, LocalAI, Jan, KoboldCpp и text-generation-webui; пресет определяется по порту, а каталог отдаёт контекст, семейство и реальные возможности моделей. Панель `/settings` → «Локальные модели» проверяет сервер и сохраняет адрес без правки `.env`. Подробности и матрица возможностей — в [LOCAL_MODELS.md](LOCAL_MODELS.md).

### Язык ответов

Все промпты проекта написаны на английском. Язык ответа задаёт переключатель интерфейса: `language_policy.py` добавляет к системному промпту английскую директиву «answer in <language>», поэтому English даёт ответ на английском, русский — на русском, таджикский — на таджикском. Промпты при этом не меняются, а добавить ещё язык можно одной записью в `language_policy.LANGUAGES`. Код, пути, команды, URL и имена инструментов не переводятся. Подробности — в [LOCAL_MODELS.md](LOCAL_MODELS.md#2-язык-ответов).

### Настройки провайдеров и моделей

Окно настроек доступно по адресу `/settings`, через кнопку-шестерёнку в верхней панели или через аватар пользователя. В нём можно выбрать OpenRouter, Groq, Cerebras или OpenAI-compatible/local endpoint. Для OpenRouter, Groq и Cerebras каталог моделей запрашивается напрямую backend через ключ из `.env`; ключи в браузер не передаются.

Каталог поддерживает фильтры по бесплатным/платным моделям, поиску, модальности text/vision, минимальному контексту, а также сортировку по рекомендуемым моделям, контексту, размеру весов, стоимости и дате. Выбранные провайдер и модель сохраняются в локальном `runtime_settings.json`, который не попадает в Git.

### Аудио, видео и изображения

Каталог картинок для основного чата: `GET /api/media/agent-image-models`. Создание и
редактирование идут через тот же `/api/agent/react`, что и другие действия. Озвучка
под ответом использует `POST /api/tts/speech`. Отдельные API `/api/media/*` для старых
клиентов и асинхронных видеозадач также остаются доступны.

### Максимальный размер файла

В `app.py`:

MAX_FILE_SIZE = 50 * 1024 * 1024  # 50 MB

### Добавление новой команды

1. Создай новый файл в папке `commands/`:
```python
# commands/my_command.py
def execute(user_input):
    return "Результат выполнения"
```

2. Зарегистрируй в `app.py`:
```python
from commands import my_command
app.route('/api/my-command', methods=['POST'])(my_command.execute)
```

export FLASK_ENV=development

## 🔐 Безопасность

⚠️ **ВАЖНО:**
- Никогда не коммить `.env`, `.session_secret`, `*.db`, `routes/uploads/` и пользовательские файлы.
- Терминал и агентные команды **выключены по умолчанию**: `TERMINAL_ENABLED=1` только в изолированном окружении.
- В production обязательны `APP_ENV=production`, `SESSION_SECRET`, сильный `ADMIN_CODE`, HTTPS и безопасные cookie.
- Загрузки проверяются по размеру, расширению и magic bytes; лимит по умолчанию 25 МБ.
- Все ответы проходят redaction секретов; скрытые рассуждения модели не показываются.
- Регулярно обновляй зависимости: `pip install --upgrade -r requirements.txt`.

Подробности: [SECURITY.md](SECURITY.md), [THREAT_MODEL.md](THREAT_MODEL.md), [DEPLOYMENT.md](DEPLOYMENT.md).

## 🆘 Troubleshooting

- **503 на `/readyz`** — проверьте файл БД и права доступа; detailed message только в логах.
- **429** — in-process rate limit; уменьшите частоту или настройте `RATE_*` и подключите Redis.
- **403 CSRF** — запрос пришёл с чужого Origin; используйте токен из `/api/csrf-token` при `CSRF_REQUIRE_HEADER=1`.
- **502 от AI** — провайдер недоступен или нет ключа; проверьте `/api/system/health`, включите fallback.
- **417/413 upload** — файл больше лимита или не совпадает magic bytes с расширением.
